# Lire un document partagé avec vous

## Étapes {#steps}
1. Ouvrez l’e-mail d’invitation et cliquez sur son lien, ou allez dans **Documents → Partagés avec moi**.
2. Un document que vous pouvez seulement lire est marqué **Lecture seule**. Ouvrez-le pour le lire.
3. Posez vos questions : **Demander à Lilia** répond (ce que dit le document, d’où vient un résultat) mais ne change rien.
4. Envie d’y travailler ? Cliquez sur **Faire une copie** (barre du haut) : vous obtenez votre propre copie modifiable ; l’original ne bouge pas.
5. Vous n’en avez plus besoin ? Sur sa carte dans Documents, **⋯ → Retirer de mes documents**. Rien n’est supprimé pour le propriétaire, et **Annuler** le remet.

Sur un téléphone, les documents partagés s’ouvrent dans le lecteur, avec *Poser une question sur ce document…* en bas.

## Ce que cela veut dire {#beginner}
- **Lecture seule** veut dire que le propriétaire vous a donné *Peut lire*. Pour modifier l’original, demandez-lui de passer votre accès à *Peut modifier*.
- Votre copie est à vous : ses modifications n’atteignent pas l’original, et le propriétaire ne la voit pas.

## Pour les utilisateurs de LaTeX {#expert}
- Un lecteur peut quand même lire le LaTeX généré (l’onglet Source, ou **Voir le LaTeX** sur un téléphone).
- Demander à Lilia fonctionne sans outils de modification pour un lecteur ; le serveur refuse le mode modification quoi que demande l’application.
