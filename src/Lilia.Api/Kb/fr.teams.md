# Travailler en équipe

## Étapes {#steps}
1. Ouvrez **Équipes** (cherchez *Équipes* dans le menu Lilia, ⌘K / Ctrl+K).
   ![Équipes](/help/img/teams/fr-1.png)
2. **Nouvelle équipe**, donnez-lui un nom, puis **Créer l’équipe**.
3. **Gérer** → **Membres** : saisissez l’e-mail d’un collègue, choisissez **Éditeur** ou **Lecteur**, puis **Inviter**.
4. Rattacher un document : dans celui-ci, **Partager** → **Accès d’équipe** → rattacher à votre équipe. Toute l’équipe peut désormais le modifier.

## Ce que cela veut dire {#beginner}
- Une équipe évite d’inviter les mêmes personnes sur chaque document : rattachez le document une fois.

## Pour les utilisateurs de LaTeX {#expert}
- Un document appartient à une équipe au plus ; le rattacher fait des membres de l’équipe ses éditeurs. Inviter quelqu’un directement reste possible en parallèle.
