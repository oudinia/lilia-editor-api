# Supprimer ou restaurer votre compte

## Étapes {#steps}
1. Si vous voulez une copie, faites d'abord **Paramètres → Vos données → Tout exporter**.
2. **Paramètres → Vos données → Supprimer le compte…**. La fenêtre indique ce qui disparaît : vos documents, et les personnes qui perdent ceux que vous avez partagés.
3. Tapez l'e-mail de votre compte, votre mot de passe, puis **Supprimer mon compte**. Vous êtes déconnecté immédiatement.
4. Vous changez d'avis ? Dans les 30 jours, reconnectez-vous : Lilia affiche **Votre compte est fermé** → **Restaurer mon compte**. Tout revient comme avant.
5. Après 30 jours, le compte et ses documents sont effacés.

## Ce que cela veut dire {#beginner}
- Tant qu'il n'est pas effacé, rien n'est perdu : la restauration rend chaque document.
- Les documents que vous avez partagés disparaissent aussi pour les personnes avec qui vous les avez partagés ; elles voudront peut-être une copie avant.

## Pour les utilisateurs de LaTeX {#expert}
- Après l'effacement, vos commentaires sur les documents des autres affichent « Deleted user » (le nom d'un compte effacé, dans toutes les langues).
- La suppression demande une connexion récente ; si Lilia vous demande de vous reconnecter, faites-le et revenez dans **Vos données**.
