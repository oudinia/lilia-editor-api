# Tout exporter

## Étapes {#steps}
1. Ouvrez **Paramètres → Vos données**.
2. **Tout exporter**. Lilia le prépare en arrière-plan ; vous pouvez quitter la page. Vous recevez un e-mail quand il est prêt.
3. De retour dans **Vos données** : **Télécharger**. Le zip reste disponible 7 jours.
4. Besoin d'un nouveau plus tard ? **En refaire un**.

## Ce que cela veut dire {#beginner}
- C'est une copie : vos documents restent dans Lilia.
- Vous seul pouvez le télécharger, une fois connecté.

## Pour les utilisateurs de LaTeX {#expert}
- Chaque document a son dossier : `document.json` (blocs, réglages et bibliographie tels que Lilia les stocke) et `latex/` (le projet LaTeX : main.tex, le .bib et les images). `account.json` contient votre profil.
- Pour exporter un seul document, utilisez **Exporter** dans l'éditeur.
