# Supprimer, restaurer et vider la corbeille

## Étapes {#steps}
1. Dans **Documents**, sur la carte d’un document : **⋯ → Mettre à la corbeille**. **Annuler** dans le message le ramène aussitôt.
2. Ouvrez la corbeille : **Documents → Corbeille** (en bas de la liste à gauche), ou le menu Lilia.
   ![La corbeille](/help/img/trash/fr-1.png)
3. Récupérer un document : **Restaurer**.
4. Le supprimer pour de bon : **Supprimer définitivement**. C’est irréversible.
5. Les documents de la corbeille sont supprimés automatiquement après 30 jours ; chacun indique le temps qu’il lui reste.

Un document qu’on a partagé avec vous propose plutôt **⋯ → Retirer de mes documents** : il quitte seulement votre liste.

## Ce que cela veut dire {#beginner}
- Mettre à la corbeille est sans risque : rien n’est perdu pendant 30 jours.
- **Supprimer définitivement** supprime vraiment, pour vous et pour tous ceux avec qui vous aviez partagé le document.

## Pour les utilisateurs de LaTeX {#expert}
- Les tableaux supprimés passent aussi par la corbeille ; les modèles, références, équations et extraits sont supprimés directement.
- Restaurer remet le document dans Documents.
