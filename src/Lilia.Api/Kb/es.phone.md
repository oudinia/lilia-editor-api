# Lilia en tu teléfono

## Pasos {#steps}
1. Abre Lilia en el navegador del teléfono e inicia sesión: llegas a **Documentos**, los más recientes primero (Hoy, Esta semana, Anteriores), con un buscador.
   ![Documentos en un teléfono](/help/img/phone/es-1.png)
2. Toca un documento para leerlo. Toca un párrafo y luego **Preguntar sobre este párrafo** para preguntar a Lilia (o cambiarlo, si puedes editar).
3. La barra inferior pregunta sobre todo el documento.
4. Arriba a la derecha: el esquema y **Vista previa del PDF**.
5. **⋯** ofrece **Compartir…**, **Revisar el documento**, **Estilo…**, **Página y ajustes…** y **Detalles del documento**.
6. Tu avatar ofrece **Apariencia**, **Idioma** y **Cerrar sesión**.

## Qué significa {#beginner}
- El teléfono sirve para leer, revisar y preguntar; cambias el documento a través de Preguntar a Lilia.
- Para escribir largo, usa un ordenador o una tableta grande: allí se abre el editor completo.
- Añade Lilia a tu pantalla de inicio para abrirla como una aplicación (menú del navegador → *Añadir a pantalla de inicio*).

## Para usuarios de LaTeX {#expert}
- Toca un bloque y luego **Ver LaTeX**: el código que genera Lilia, con ese bloque resaltado.
- Los ajustes de página cambiados en el teléfono (papel, columnas, tamaño de letra, márgenes…) se guardan al momento y ofrecen **Deshacer** unos segundos.
