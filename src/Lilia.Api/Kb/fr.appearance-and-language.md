# Changer le thème, l’accent et la langue

## Étapes {#steps}
1. Cliquez sur votre avatar (en haut à droite) → **Paramètres**, puis **Apparence**.
   ![Paramètres, Apparence](/help/img/appearance-and-language/fr-1.png)
2. **Thème** : **Système** (suit votre ordinateur ou téléphone, clair le jour et sombre la nuit), **Clair** ou **Sombre**.
3. **Accent** : **Céruléen**, **Prune** ou **Encre** : la couleur des boutons, liens et sélections.
4. **Style clair (à l’essai)** : la façon dont le mode clair sépare les éléments (Crisp par défaut).
5. **Langue** : English, Français ou Español. La page se recharge dans cette langue.

Les changements s’appliquent immédiatement, partout. Plus rapide : le bouton lune/soleil de la barre du haut bascule entre clair et sombre ; **Thème et accent…** dans le menu de l’avatar ouvre les mêmes choix. Sur un téléphone : avatar → **Apparence** et **Langue**.

## Ce que cela veut dire {#beginner}
- Ces réglages changent l’apparence de Lilia pour vous, pas celle de votre article. Pour l’article lui-même, voyez *Choisir le style de votre article*.
- Demander à Lilia répond dans la langue où vous écrivez, quelle que soit celle de l’interface.

## Pour les utilisateurs de LaTeX {#expert}
- La langue de l’interface est distincte de celle du document (dans ses réglages de page), qui règle la césure et les mots propres à LaTeX (Table des matières, Figure, Références).
