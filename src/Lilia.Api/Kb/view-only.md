# Read a document someone shared with you

## Steps {#steps}
1. Open the invitation email and click its link, or go to **Documents → Shared with me**.
2. A document you can only read is marked **View only**. Open it to read it.
3. Ask about it: **Ask Lilia** answers questions (what it says, where a result comes from) but changes nothing.
4. Want to work on it? Click **Make a copy** (top bar): you get your own editable copy; the original stays as it is.
5. Done with it? On its card in Documents, **⋯ → Remove from my documents**. Nothing is deleted for the owner, and **Undo** brings it back.

On a phone, shared documents open in the reader, with *Ask about this document…* at the bottom.

## What this means {#beginner}
- **View only** means the owner chose *Can view* for you. To edit the original, ask the owner to change your access to *Can edit*.
- Your copy is yours: changes to it don't reach the original, and the owner doesn't see it.

## For LaTeX users {#expert}
- A viewer can still read the generated LaTeX (the Source tab, or **View LaTeX** on a phone).
- Ask Lilia runs without edit tools for a viewer; the server refuses edit mode regardless of the client.
