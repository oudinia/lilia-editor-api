# Trabaja en equipo

## Pasos {#steps}
1. Abre **Equipos** (busca *Equipos* en el menú de Lilia, ⌘K / Ctrl+K).
   ![Equipos](/help/img/teams/es-1.png)
2. **Nuevo equipo**, ponle nombre y **Crear el equipo**.
3. **Gestionar** → **Miembros**: escribe el correo de un colega, elige **Editor** o **Lector** e **Invitar**.
4. Vincular un documento: en él, **Compartir** → **Acceso de equipo** → vincúlalo a tu equipo. Todo el equipo puede editarlo desde ese momento.

## Qué significa {#beginner}
- Un equipo te ahorra invitar a las mismas personas a cada documento: vincula el documento una vez.

## Para usuarios de LaTeX {#expert}
- Un documento pertenece como mucho a un equipo; vincularlo convierte a sus miembros en editores. Invitar a alguien directamente sigue siendo posible.
