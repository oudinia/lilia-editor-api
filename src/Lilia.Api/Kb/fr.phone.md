# Lilia sur votre téléphone

## Étapes {#steps}
1. Ouvrez Lilia dans le navigateur du téléphone et connectez-vous : vous arrivez sur **Documents**, les plus récents d’abord (Aujourd’hui, Cette semaine, Plus ancien), avec une recherche.
   ![Documents sur un téléphone](/help/img/phone/fr-1.png)
2. Touchez un document pour le lire. Touchez un paragraphe, puis **Poser une question sur ce paragraphe** pour interroger Lilia (ou le modifier, si vous en avez le droit).
3. La barre du bas pose une question sur tout le document.
4. En haut à droite : le plan, et **Aperçu du PDF**.
5. **⋯** propose **Partager…**, **Vérifier le document**, **Style…**, **Page et réglages…** et **Détails du document**.
6. Votre avatar propose **Apparence**, **Langue** et **Se déconnecter**.

## Ce que cela veut dire {#beginner}
- Le téléphone sert à lire, vérifier et demander ; vous modifiez le document via Demander à Lilia.
- Pour écrire longuement, utilisez un ordinateur ou une grande tablette : l’éditeur complet s’y ouvre.
- Ajoutez Lilia à votre écran d’accueil pour l’ouvrir comme une application (menu du navigateur → *Sur l’écran d’accueil*).

## Pour les utilisateurs de LaTeX {#expert}
- Touchez un bloc, puis **Voir le LaTeX** : la source produite par Lilia, ce bloc en surbrillance.
- Les réglages de page modifiés sur un téléphone (papier, colonnes, taille du texte, marges…) s’enregistrent aussitôt et proposent **Annuler** quelques secondes.
