# Paramètres : votre compte et vos préférences

## Étapes {#steps}
1. Ouvrez les **Paramètres** : l'avatar (en haut à droite) → **Paramètres**, ou le menu Lilia. Sur un téléphone : l'avatar sur **Documents** → **Paramètres**.
2. Sous **Compte** :
   - **Profil** : le nom que les autres voient sur vos commentaires, partages et présence. Modifiez-le, puis **Enregistrer** dans la barre qui apparaît (**Annuler** revient en arrière).
   - **Sécurité** : **Changer le mot de passe** : votre mot de passe actuel, puis le nouveau. Vous restez connecté.
   - **Offre** : votre offre et ce que vous en avez utilisé ce mois-ci.
   - **Applications connectées** : les applications d'IA connectées à Lilia, comme Claude. **Déconnecter** en arrête une immédiatement.
   - **Vos données** : **Tout exporter**, et **Supprimer le compte…**.
3. Sous **Préférences** :
   - **Apparence** : thème (Système, Clair, Sombre), accent, langue.
   - **Demander à Lilia et aide** : comment Lilia explique (Simple, Standard, Pour les utilisateurs de LaTeX).
   - **Éditeur** : valeurs par défaut des nouveaux documents, enregistrement automatique, édition LaTeX ; **Dépannage** → **Vider le cache et recharger**.

## Ce que cela veut dire {#beginner}
- Votre e-mail est l'adresse avec laquelle vous vous connectez ; il est affiché dans Profil mais change avec votre connexion, pas ici.
- Les changements d'apparence s'appliquent tout de suite ; rien à enregistrer.

## Pour les utilisateurs de LaTeX {#expert}
- Chaque section a sa propre adresse : /settings/profile, /settings/security, /settings/billing, /settings/apps, /settings/data.
- L'édition LaTeX (Éditeur) montre les commandes et la source dans l'éditeur.
